# ESP32-2432S028 — монитор температур ПК + частичное управление

Панель на 2.8" сенсорном экране (320×240) показывает температуры CPU/GPU,
накопители и обороты кулеров с ПК, а по касаниям управляет ПК: сон/выключение,
громкость/плей-пауза, запуск приложений. Связь — по Wi‑Fi (TCP), ПК выступает
сервером, ESP32 — клиентом.

```
esp32-pc-monitor/
├─ firmware/        # прошивка ESP32 (PlatformIO + Arduino + LVGL 8)
│  ├─ platformio.ini
│  ├─ lv_conf.h
│  └─ src/
│     ├─ config.h   # ← сюда вписать WiFi и IP компьютера
│     └─ main.cpp
└─ pc-agent/        # агент на Windows-ПК (Python)
   ├─ pc_agent.py   # TCP-сервер: шлёт телеметрию, принимает команды
   ├─ telemetry.py  # чтение датчиков (LibreHardwareMonitor → psutil/nvidia-smi)
   ├─ control.py    # сон/выключение/громкость/медиа/запуск приложений
   ├─ config.ini    # порт, интервалы
   ├─ apps.json     # что запускать по кнопкам App 1/2/3
   └─ requirements.txt
```

## Быстрый старт (режим Serial — по умолчанию, без роутера)
Модуль включён в ПК обычным USB-кабелем (порт для прошивки, CH340 → `COM5`).
Телеметрия и команды идут по этой же линии, Wi‑Fi не нужен.

1. Прошейте прошивку: `cd firmware && pio run -t upload --upload-port COM5`
   (PlatformIO не любит кириллицу в пути — если сборка падает на `cannot open map file`,
   соберите из ASCII-папки, напр. `C:\esp32-build`).
2. Установите датчики: запустите **LibreHardwareMonitor от админа** и включите
   `Options → WMI Provider` (см. шаг 3 ниже) — иначе температуры будут нулевые.
3. `cd pc-agent && python -m pip install -r requirements.txt && python pc_agent.py`
   Агент откроет `COM5` из `config.ini` и начнёт слать данные; на экране появятся
   CPU/GPU/диски/кулера. Кнопки на экране (Sleep/Power/громкость/App) шлют команды обратно.
   Чтобы агент запускался вместе с Windows — создайте `.bat` в `shell:startup`.

Всё остальное ниже — про Wi‑Fi-вариант и детальную настройку.

## 0. Что понадобится
- ESP32-2432S028 (классический: ILI9341 + XPT2046, ESP32-WROOM-32, 4 МБ флеш).
- Кабель USB → плата (подключается в порт **для ESP32/UART**, обычно подписан ESP32,
  на микросхеме CH340). У платы два USB — используйте тот, что для прошивки.
- Windows 10/11, Python 3.9+, VS Code + PlatformIO (или CLI `pio`).
- LibreHardwareMonitor (для полных датчиков) — см. шаг 3.
- Драйвер CH340, если Windows не видит COM-порт.

## 1. Прошивка ESP32
1. Откройте папку `firmware/` в VS Code с PlatformIO (или `cd firmware && pio run`).
2. Режим по умолчанию — **Serial по USB**: правки в `src/config.h` не нужны
   (там только скорость порта и тайминги). Для Wi‑Fi варианта см. ниже раздел «3. Агент на ПК»
   и поставьте в `pc-agent/config.ini` `type = tcp` (потребуется пересобрать прошивку под TCP).
3. Прошейте:
   ```bash
   pio run -t upload            # сборка + прошивка
   # если ругается на порт:
   pio run -t upload --upload-port COM5
   ```
   При зависании загрузки зажмите кнопку **BOOT** на плате при старте прошивки.
4. Мониторинг логов: `pio device monitor` (115200) — виден IP панели и телеметрия.

## 2. Раздача питания
Экран + Wi‑Fi берут прилично тока. Два варианта:
- от USB компьютера (тогда COM-порт тот же, но для Wi‑Fi-режима кабель можно воткнуть
  и в обычное зарядное 5V/1A);
- от второго USB / повербанка — плата работает автономно, данные идут по Wi‑Fi.

## 3. Агент на ПК
```powershell
cd pc-agent
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```
Полные датчики (CPU/GPU/SSD/кулеры) берутся из **LibreHardwareMonitor через WMI**:
1. Скачайте [LibreHardwareMonitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor)
   (или возьми уже распакованный в `C:\LHM\LibreHardwareMonitor.exe`).
2. Запусти **от администратора** (правой кнопкой → «Запуск от администратора» / UAC).
3. **Включи WMI-провайдер вручную: меню `Options` → отметь `WMI Provider`.**
   Он по умолчанию ВЫКЛЮЧЕН, и без этого пункта панель не увидит ни одной температуры
   (`root/LibreHardwareMonitor` просто не появится в WMI).
4. Держи открытым (можно свернуть в трей). Если LHM нет/не включён — агент откатится на
   psutil + `nvidia-smi` (будет только загрузка CPU и, при наличии, GPU NVIDIA; кулеров не будет).

Запуск агента (тоже от администратора — иначе сон/WMI могут не работать):
```powershell
python pc_agent.py
```
Он напечатает, например: `IP этого ПК в локальной сети: 192.168.1.50` —
впишите его в `SERVER_IP` в `firmware/src/config.h` и перепрошейте (или агент
печатает IP, а панель подключается к нему автоматически после перезагрузки Wi‑Fi).

### Разрешите порт в брандмауэре (один раз, от админа)
```powershell
netsh advfirewall firewall add rule name="pc-agent ESP32" dir=in action=allow protocol=tcp localport=8765
```

## 4. Настройка кнопок «Быстрый запуск»
Не руками править JSON — запусти графический редактор:
```
D:\ЗАИ\esp32-pc-monitor\pc-agent\apps_config.bat      (двойной клик, права не нужны)
```
Там: **Добавить / Изменить / Удалить / Выше / Ниже**, выбор файла или папки через диалог,
поле «Аргументы», галка «shell» (для папок/ссылок), кнопка **Тест-запуск** и **Сохранить**.
Порядок строк = порядок кнопок на экране (1-я строка → 1-я кнопка). Максимум 4 кнопки на
панели (всё, что выше, агент просто не показывает на экране, но `launch idx` работает).

После «Сохранить» ничего перезапускать не надо: агент читает `apps.json` при каждой
отправке, и названия кнопок сразу обновляются на панели (кириллица поддерживается).

Хочешь редактировать JSON напрямую — формат:
```json
[
  { "name": "Игра",  "path": "C:\\Games\\game.exe", "args": ["-fullscreen"] },
  { "name": "Chrome","path": "%ProgramFiles%\\...\\chrome.exe" },
  { "name": "Папка", "path": "D:\\ЗАИ", "shell": true }
]
```
- `args` — параметры запуска; `~` и `%VARS%` раскрываются автоматически.
- `"shell": true` — открыть как в Проводчике/через `start` (папки, ссылки).

## 4.5. Автозапуск агента от админа (чтобы °C CPU были всегда)
Один раз зарегистрируй задачу планировщика (нужно подтверждение UAC):
```
правой клик по pc-agent\register_task.ps1 → «Запуск с повышением»
```
или из админ-PowerShell:
```
powershell -ExecutionPolicy Bypass -File "D:\ЗАИ\esp32-pc-monitor\pc-agent\register_task.ps1"
```
Создаётся задача **ZaiPcAgent**: запуск при входе в систему, наивысшие права, в твоей
сессии (чтобы `SendInput` громкости/медиа тоже работал). Она запускает
`run_agent.cmd` → `pythonw.exe pc_agent.py` без окна. Отключить:
```
schtasks /Delete /TN ZaiPcAgent /F
```
Ручной запуск/перезапуск агента сейчас: `pc-agent\start_admin.bat`.

## 5. Управление с экрана (кнопки)
| Кнопка | Действие |
|--------|----------|
| **Power**   | выключение ПК (`shutdown /s /t 5`; отмена в консоли: `shutdown /a`) |
| **Sleep**   | сон/гибернация |
| **− / +**   | тише / громче (виртуальные клавиши громкости) |
| **Mute**    | без звука |
| **Play**    | плей/пауза медиаплеера |
| **Быстрый запуск 1..N** | запуск приложений из `apps.json` (названия — как в редакторе) |

## 6. Протокол (если хотите расширять)
Одна JSON-строка за строкой `\n` в обе стороны.

ПК → панель (каждые `telemetry_interval_ms`):
```json
{"cpu":{"t":57.3,"load":31.2},
 "gpu":{"t":61.0,"load":44.0},
 "storage":[{"name":"SSD","t":38.1}],
 "fans":[{"name":"CPUFan","rpm":1180}]}
```
Панель → ПК:
```json
{"cmd":"sleep"}
{"cmd":"vol_up"}
{"cmd":"launch","idx":0}
```
Чтобы добавить новую команду: обработайте её в `control.py::execute`
(реестр) и отправьте свой `{"cmd":"..."}` из прошивки (функция `sendCmd`).

## 7. Частые проблемы
- **Панель пишет «Поиск сети…»** — неверный SSID/пароль или сеть 5 ГГц; проверьте лог
  `pio device monitor`.
- **«Нет коннекта»** — не совпадает `SERVER_IP`, агент не запущен или порт закрыт
  брандмауэром (см. шаг 3).
- **«Нет данных»** — соединение есть, но телеметрия не приходит: LHM не запущен
  от админа / WMI-датчики не видны.
- **Экран вверх ногами / тач мимо** — поменяйте `tft.setRotation()` и ветки маппинга
  в `touch_read()` (строки `int x = map(...)`).
- **Датчики пустые / CPU без °C / дисков нет** — на этом железе температура CPU и SMART-температуры
  дисков отдаются LibreHardwareMonitor **только от администратора** (нужен ring0-драйвер).
  Запусти `pc-agent\start_admin.bat` (или просто агент из «терминала администратора») —
  `cpu t` станет не `0.0`. Если даже с админом дисков нет — контроллер этих накопителей не
  отдаёт температуру; это ограничение железа, в панели эти поля просто не показываются.
- **Квадраты вместо букв** — в панели теперь кириллический шрифт (`cyr14/20/28.c`, собран из tahoma).
  Если добавишь новый размер — перегенерируй: `npx lv_font_conv --font C:/Windows/Fonts/tahoma.ttf --size 16 --bpp 4 --format lvgl --range 0x20-0x7E --range 0x410-0x44F -o src/cyr16.c` (и `#include "lvgl.h"` вместо `lvgl/lvgl.h`).

## 8. Развёртка
Классический 2432S028 на XPT2046 в этой прошивке откалиброван «на глаз»
(диапазон сырых значений 200–4000 на всю область экрана). Если касание уходит не туда,
подстройте границы `constrain(p.y/p.x, 200, 4000)` в `touch_read()`.
